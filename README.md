# Sistema de Gestão Hoteleira

Sistema desktop desenvolvido em Java e JavaFX para controle simples e eficiente de quartos de hotel, status de ocupação e previsão de diárias.

## Funcionalidades

* Cadastro de Quartos: Adicione quartos informando número, categoria e valor da diária.

* Controle de Status: Identifica se o quarto está Vago ou Ocupado.

* Bloqueio de Reserva: Impede que um quarto já ocupado seja reservado novamente por engano.

* Previsão de Desocupação: Exibe em quantos dias o quarto ficará vago novamente com base na data de check-out informada.

* Interface: Dashboard visual em cards com código de cores para status.

## Tecnologias Utilizadas

* Java
* JavaFX
* Maven 

### Pré-requisitos

Antes de executar o projeto na sua máquina, certifique-se de ter instalado:

* JDK 17+ 

* IDE compatível com Java e JavaFX
